Descripción del proyecto

Este Objeto Virtual de Información fue desarrollado con el propósito de presentar contenidos educativos relacionados con la lógica computacional de una manera clara, organizada e interactiva.

El sitio incluye lecturas, recursos multimedia y actividades de aprendizaje que permiten al estudiante estudiar conceptos fundamentales como las proposiciones, los operadores lógicos, los valores de verdad y las tablas de verdad.

Tecnologías utilizadas

  • HTML5
  • CSS3
  • GitHub Pages

Sobre este OVI

Este sitio web presenta contenidos educativos relacionados con la lógica computacional y está diseñado para facilitar el aprendizaje mediante lecturas, recursos multimedia y actividades.
